# 영웅 카드 배틀

도감 카드로 하는 턴제 카드 게임. 규칙은 흔한 수집형 카드 게임 방식(카드를 필드에 내고, 공격해서 상대 대장 체력을 0으로)이고,
이름·그림·화면은 우리 도감 것만 씁니다 (듀오링고 스타일, docs/DESIGN.md).

## 카드 숫자 (`src/lib/battle/cards.ts`)

도감 능력치에서 자동으로 나옵니다.

| 숫자 | 정하는 법 |
|---|---|
| ⚡ 비용 | 별 개수 − 1 (1~4). 도감 인물은 대부분 4~5성이라 별 그대로면 처음 몇 차례에 낼 카드가 없음 |
| ⚔️ + ❤️ | 합 = 비용 × 2 + 3 |
| 나누기 | 한 능력치만 높으면 공격 쪽(여포 9/2, 장비 7/2), 골고루 높으면 체력 쪽(관우 5/6) |

처음 계획(비용=별, 공격=최고÷20, 체력=평균÷15)은 거의 모든 카드가 ⚔️5·⚡4~5로 같아져서 바꿨습니다.

**특별한 힘** (공식 세계관의 종류만)

| 힘 | 종류 | 효과 |
|---|---|---|
| 🛡️ 지키기 | 장수, 영웅 | 상대는 이 카드부터 공격해야 함 |
| 💨 돌격 | 괴물 | 내자마자 공격 가능 |
| 📜 꾀 | 책사 | 낼 때 카드 1장 더 뽑기 |
| ✨ 신의 힘 | 신 | 낼 때 상대 카드 모두에게 1 피해 |

## 규칙 (`src/lib/battle/engine.ts`, 순수 함수)

- 대장 체력 20, 덱 10장. 먼저 하는 쪽 3장, 나중 쪽 4장으로 시작.
- 내 차례: 에너지 칸 +1 (첫 차례 2, 최대 6) → 가득 채움 → 1장 뽑기. 덱이 비면 대장이 1, 2, 3… 피해.
- 카드 내기: 에너지 = 비용. 필드 최대 5칸, 손패 최대 7장(넘치면 뽑은 카드가 버려짐).
- 낸 차례에는 공격 못 함(돌격 예외). 카드끼리 공격하면 서로 공격력만큼 피해.
- 상태를 바꾸지 않고 새 상태를 돌려줌. 섞기는 상태 안의 seed로 (같은 seed = 같은 게임).

## 토리 (`src/lib/battle/ai.ts`)

이길 수 있으면 대장 공격 → 가장 비싼 카드 내기 → 유리한 교환 → 대장 공격. 일부러 단순하게 했습니다.
1,000판 시뮬레이션에서 "아무 카드나 내고 대장만 때리는" 단순한 방법으로 아이가 약 63% 이깁니다. 한 판은 양쪽 합 13차례 정도.

덱은 자동: 비용이 고르게 섞이도록 고르고, 내가 만든 영웅(최대 3장)을 먼저 넣습니다. 토리 덱은 공식 인물에서.

## 화면 (`/battle`)

대장 고르기 → 게임. 손패 카드를 누르면 내기, 필드의 내 카드(초록)를 누르고 빨간 대상을 누르면 공격.
토리 차례는 0.9초 간격으로 하나씩. 피해 숫자, 흔들림, 카드 등장 애니메이션 (움직임 줄이기 설정이면 끔).
